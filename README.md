# Modular Magnetic Keyboard

A keyboard where every key snaps onto the base with magnets. Copper tape under each key carries the signal, so switches attach without wiring or soldering and a layout can be rearranged in seconds.

Designed in Onshape and printed on a Flashforge Adventurer 3.

## Status
Early prototype. The key module is on its third revision; electronics and the base plate are next.

## Files

| File | What it is |
|---|---|
| `cad/modularKeys-V3-bigMag.stl` | **Current.** V3 key module with one larger magnet |
| `cad/modularKeys-V2-duomag-shorterbase-lighterswitch.stl` | V2 key module: two magnets, shorter base, lighter switch |

## Revision history
- **V2 (duomag):** two magnets per key; later trimmed to a shorter base and a lighter switch.
- **V3 (bigMag):** a single larger magnet for a firmer snap.

## Printing
Open the `.stl` in any slicer.
